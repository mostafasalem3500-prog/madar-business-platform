# مدار الأعمال

نموذج واجهة عربية RTL عالي الدقة لمنصة سعودية تجمع خدمات تأسيس وتشغيل وتطوير المنشآت.

## التشغيل

لا يحتاج النموذج إلى تثبيت حزم. افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
npx serve .
```

## ما يعمل في النسخة الحالية

- تصميم Responsive عربي كامل مع قائمة هاتف.
- بحث لحظي وفلاتر لـ 12 مسار خدمة.
- تبويبات رحلة المنشأة ومقارنة الباقات.
- قسم «الخدمات الحكومية المنفردة» تحت الباقات: 278 خدمة موزعة على 20 جهة (التجارة، قوى، الجوازات، بلدي، سلامة، الزكاة، التأمينات، مدد، الغرف التجارية، الإعلام، الخارجية، العدل، مساند…) مع بحث وسلة طلب متعددة الخدمات تُرسل إلى نموذج الطلب. البيانات الافتراضية في `data/catalog.json` وتُدار من لوحة التحكم (صفحة «الخدمات المنفردة»).
- نموذج طلب متعدد الخطوات مع تحقق أساسي.
- تجربة تتبع للطلب `MD-2048`.
- لوحة عميل تجريبية.
- حركات دخول وMicro-interactions ودعم `prefers-reduced-motion`.
- محتوى أصلي بلا ادعاءات أو شراكات غير موثقة.


## لوحة التحكم (`/admin.html`)

لوحة إدارة كاملة للمنصة:
- **لوحة القيادة:** مؤشرات الطلبات، رسم بياني لآخر 14 يومًا، توزيع الحالات، آخر الطلبات والتغييرات.
- **الطلبات:** كل طلب يُرسل من الموقع يُحفظ على الخادم (`storage/orders.json`). تغيير الحالة، تعيين مسؤول، قيمة العرض، ملاحظة تظهر للعميل، ملاحظات داخلية، حذف، وتصدير Excel (CSV).
- **تتبّع الطلب الحقيقي:** العميل يتتبع برقم الطلب + آخر 4 أرقام من جواله.
- **الباقات والخدمات المنفردة:** إضافة وتعديل وحذف وترتيب.
- **التصميم:** قوالب ألوان جاهزة، 5 ألوان، خطوط العناوين والنصوص، الحركة، CSS مخصص — مع **معاينة حية** قبل النشر (كمبيوتر/تابلت/جوال).
- **نصوص الموقع:** تعديل أي عنوان أو فقرة أو زر في الصفحة الرئيسية.
- **الأقسام:** إظهار/إخفاء وترتيب ظهور الأقسام.
- **الأسئلة الشائعة، شريط القطاعات، مراحل المنشأة، الصور والأنشطة، مركز المعرفة.**
- **الإعدادات:** التواصل، واتساب، حسابات التواصل الاجتماعي، SEO، شريط الإعلانات، نسخ احتياطي واستعادة.
- **سجل التغييرات:** كل نشر وتحديث طلب.

### الدخول
- `ADMIN_OPEN=true` ← اللوحة تعمل بلا كلمة مرور (مؤقتًا).
- لإعادة الحماية: احذف `ADMIN_OPEN` وتُستخدم `ADMIN_PASSWORD`.

## الانتقال للإنتاج

هذه نسخة Front-end تشغيلية. يحتاج الإنتاج إلى ربط الواجهات بقاعدة PostgreSQL، مصادقة، تخزين ملفات، لوحة إدارة فعلية وبوابة دفع. البنية المقترحة: Next.js + TypeScript + Prisma + PostgreSQL، ثم Docker وRailway.

جميع أرقام التواصل والهوية وبيانات الطلبات الحالية تجريبية ويجب استبدالها قبل النشر.
